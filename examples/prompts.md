# Prompt Examples

这些示例用于调用 `$kevinbee-illustrations` 的正文配图能力。

## 只做配图规划

```text
Use $kevinbee-illustrations 先不要生成图片。

分析下面这篇文章，只挑真正值得视觉化的认知锚点，输出 4–6 张 shot list。
每张说明：放置位置、核心意思、结构类型、凯冰如何自然进入场景、主要物件，以及是否需要短标注。

<粘贴文章>
```

## 生成文章正文配图

```text
Use $kevinbee-illustrations 为下面这篇文章生成 4 张正文配图。

要求：保持凯冰 V2 身份一致，默认无文字；一张只表达一个核心关系。不要画成 PPT、流程图皮肤或角色海报。

<粘贴文章>
```

## 长文配图策略

```text
Use $kevinbee-illustrations 给这篇长文制定配图策略，先不要生成图片。

不要平均配图。优先寻找核心判断、认知转折、关系断点、选择与分流、状态变化。总数控制在 6–8 张。

<粘贴文章>
```

## 单个观点

```text
Use $kevinbee-illustrations 为这个观点生成一张 16:9 正文配图：

真正的选择不是找到最亮的路，而是放弃其他同样可能的路。

默认无文字。让凯冰自然处在选择之中，不要让她操作机器或扮演工作人员。
```

## 情绪与状态

```text
Use $kevinbee-illustrations 为“信息很多，但没有一条真正属于自己”生成一张正文配图。

重点表现凯冰的状态与空间关系。保持清爽留白，不要用界面、图表或大量标签解释。
```

## 系统或流程主题

```text
Use $kevinbee-illustrations 为“输入没有形成稳定输出，是因为中间关系不断断开”生成一张正文配图。

可以表现流动与断点，但不要复用传送带、分拣机、内容工厂或维修员构图。凯冰可以经历或观察这个关系，不必负责修理它。
```

## 修改错误文字

```text
Use $kevinbee-illustrations 编辑这张图。

只删除错误文字和对应下划线，填回干净背景。保持凯冰身份、姿态、核心隐喻、线条、颜色和画幅不变；不要新增物件。
```

## 调整角色参与方式

```text
Use $kevinbee-illustrations 重画这张图。

核心意思和主要构图保持不变，但不要让凯冰像工作人员一样操作系统。让她自然地经历、观察、选择、同行或轻微影响场景。保持 V2 休闲形象，不增加工具、制服或标签。
```
