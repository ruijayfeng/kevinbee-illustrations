# V2 development archive

这里保存凯冰 V2 建立过程中的方向探索、早期验证、已废弃正文比例和过渡参考。它们用于追溯设计决策，不属于当前 Skill 的运行时资产。

- `explorations/`：服装、标准形态、早期轻 Q 与姿势模板候选。
- `validation-v2.1/`：V2.1 阶段的表情、动作与正文场景验证，包含原始比例文件；已晋升的正式示例不在这里重复保存。
- `retired-skill-assets/v2.1-article-form/`：被 V2.2 取代的三头身正文实验。

早期标准形态、正文形态、表情表和动作表如果与 `explorations/` 或 `validation-v2.1/` 完全相同，只保留一份，不另建“过渡参考”副本。

当前身份、正文比例和可加载资产只以 `kevinbee-illustrations/references/` 与 `kevinbee-illustrations/assets/manifest.yaml` 为准。除非任务明确要求追溯或比较，不要把本目录图片提供给图像模型。
