# V2.1 标准版封面基线

这些图复制自现有文章项目的已生成封面，用于核对这次整合是否保住原有封面的视觉方向。它们不是 Skill 安装资产，也不提供固定姿势、人物位置或字效模板；文章仍决定场景与动作。

| 图 | 原项目来源 | 值得保留的设计关系 |
|---|---|---|

| `02-nano-work.png` | `assets/kevinbee-cover-title-tests/02-nano-work.png` | 安静的成年姿态和细微表情；标题以由深到浅的字色融入空间，与其他封面字效不同。 |
| `03-remote-assistance.png` | `assets/jiedianxiaobao-remote-assistance-cover/cover-with-title.png` | 人物在截图与远程屏幕之间建立动作关系；中文标题清楚，帽星、脸、双手和主对象在宽幅中完整。 |

三张原图约 2.35:1，均另存 240px 宽缩略图。检查时可辨标题、白帽红星、凯冰神情和主题对象。对照 `../2026-09-29-composition-forward/` 的强 Q 封面实验，差别不只是比例：标准版的肩颈、手部、眼神与标题空间一起构成了更成熟的编辑封面观感。今后判断封面不能只用字符准确率、裁切和缩略图尺寸代替这一层视觉验收。
