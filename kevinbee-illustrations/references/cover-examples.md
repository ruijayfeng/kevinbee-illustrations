# 封面案例：按需复盘

封面是与正文配图并列的 Skill 功能。先读文章，确定主对象、阅读承诺、可见事件、凯冰的参与方式和目标画幅；完成构思后，才按需要查看下列成图，比较人物、主对象、标题与空间的关系。每篇文章重新决定隐喻、动作、景别、站位、道具和字效。

人物身份与比例始终按 `character-model.md` 和 `assets/manifest.yaml` 中的标准形态参考校准。**下列封面均不用于校准肩峰、袖量或骨架**；现有标准母版的肩袖外轮廓仍待验收。

## 既有文章封面

这三张是已生成的文章封面，用于观察封面整体观感。它们也不提供通用版式或人物比例结论。

| 成图 | 可复盘的设计关系 |
|---|---|
| [微缩房间](../assets/cover/editorial-examples/seed-miniature-room.png) | 近景人物托住微缩场景；标题、人物和主对象都有可辨体量。 |
| [纳米工作](../assets/cover/editorial-examples/nano-work.png) | 安静神情与坐姿；标题融入留白，强调克制的编辑封面观感。 |
| [远程协助](../assets/cover/editorial-examples/remote-assistance.png) | 人物在截图和远程屏幕之间建立动作关系；宽幅中保留脸、帽星、双手和主对象。 |

## 内容构思研究

这四张以用户提供的其他作者封面为设计参考、以凯冰标准母版为身份参考重新生成。原始对应文章未提供，表中内容关系是从画面反推的**设计假设**，不代表产品能力或文章事实。研究图中的肩袖比例尚未合格。

| 成图 | 假设的内容关系 | 可复盘的事件 |
|---|---|---|
| [多结果分岔](../assets/cover/concept-studies/qwen-branching.png) | 一个来源产生多类结果 | 凯冰托住起点，视线跟随结果展开。 |
| [进入产品世界](../assets/cover/concept-studies/hyper3d-forward.png) | 进入有鲜明质感的空间 | 人物骑行进入场景，标题成为路景的一部分。 |
| [动作冲击](../assets/cover/concept-studies/fighting-skill-impact.png) | 动作技能的瞬间冲击 | 前景拳头与身体形成动势；只适用于文章确实讨论动作技能时。 |
| [一次示范带出后续](../assets/cover/concept-studies/teach-once-causal.png) | 第一次触发后出现连续步骤 | 点击动作、光路和结果形成因果链。 |

这些图保存的是**封面功能的设计资料**。生成新封面时，默认图像输入仍是标准形态身份母版；案例仅在构思完成后供人工复盘，不直接作为图像参考或模板。短标题、图内文字、实际尺寸和最终裁切仍按 `cover-prompt.md` 与 `cover-qa.md` 验收。
