# 凯冰 V2.3：标准身份与正式 Q 版参考

本文件只负责角色比例、角度与图片参考的选择。凯冰是谁以 `ip-core.md` 为准；文章隐喻和动作先由正文决定，参考图随后校准身份与造型。

## 两层形象

- **V2.1 标准形象**：`assets/ip-reference/v2.1/00-canonical-master.png` 保留脸、白帽红星、冰蓝短发、暗红开衫和基本配色。标准形象可用于身份核对、标准形态展示和头肩近景；它不控制正文 Q 版的全身比例。
- **V2.3 正文 Q 版**：`assets/ip-reference/v2.3/00-strong-q-master-front.png` 是正式正面母版。大头帽、短颈躯、短而可活动的腿、小手和圆厚鞋构成独立设计的 Q 版身体，不是把标准形象在画布上等比缩小。圆厚或显幼态的视觉比例可以成立；角色的身份、气质和文章中的行动能力仍保持凯冰。

V2.2 轻 Q 图片已移至仓库 `archive/development-v2/retired-v2.2-runtime/`，只用于历史追溯，不参与新图生成或比例核对。不要用 V2.1 标准全身图与 V2.3 Q 版全身图同时约束同一张正文图，以免比例冲突。

## 参考如何参与生成

先定当前文章的隐喻、空间关系和凯冰的动作，再从上表选一张最接近角度的图片。复杂动作或情绪可先靠文字描述；只有实际出现身份漂移时，才增加另一张直接相关的参考，并说明它只校准哪一处。历史 V2.2 动作表、表情表和旧文章案例不是 V2.3 的纠偏池，不再加载。

参考图不提供默认姿势、隐喻物件或固定构图。可以在文章需要时让凯冰坐、蹲、回头、伸手或采取新的动作；显幼态的比例和圆厚肢体不是淘汰条件。检查的是动作方向、重心与隐喻物的因果接触能否看懂，以及帽、发、眼、衣和整体 Q 版轮廓是否连续。

近景可用 V2.1 母版和相应头部单图校准脸与帽结构；如果近景明确表现正文 Q 版，则以 V2.3 母版控制头身和气质，不以标准形态的成年骨架把 Q 感拉回去。标准形象侧面或背影仍按 V2.1 单视图生成。
