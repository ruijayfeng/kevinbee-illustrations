# 凯冰 V2.2：角色模型与参考路由

本文件定义如何使用角色设定资产。角色身份仍以 `ip-core.md` 为唯一文字真值；V2.1 标准身份层与 V2.2 正文轻 Q 层各自解决不同问题，不能混成同一套比例。

## 权威顺序

发生视觉冲突时，按以下顺序判断：

1. `assets/ip-reference/v2.1/00-canonical-master.png`：脸、发型、帽子、配色与成年气质。
2. `assets/ip-reference/v2.2/00-q-form-master-front.png`：正文轻 Q 的内部比例、成年骨架和服装长度。
3. `assets/ip-reference/v2.2/01-q-form-four-view.png`：正文形态跨角度的共同基准线。
4. `assets/ip-reference/v2.2/q-form-views/`：指定角度的正文全身结构。
5. V2.1 头部与标准五视图：只补充近景或标准形态结构，不参与正文全身比例竞争。
6. 表情表与动作表：只约束情绪和姿态，不得反向改写身份或比例。

## 两个参考层

### V2.1 标准身份层

`v2.1/00-canonical-master.png` 保持约 5–5.5 头身，用于身份核对、标准形态展示与头肩近景。`turnaround-views/` 和 `head-views/` 分别补充全身和头部角度。

### V2.2 正文轻 Q 层

`v2.2/00-q-form-master-front.png` 是正文正面母版，约 4.0–4.5 头身。它不是标准形态的整体缩小版：人物仍保留成年脸、肩腰胯和膝盖结构，通过相对放大头部、适度缩短躯干与四肢，以及同步缩短服装形成轻 Q 感。

`v2.2/01-q-form-four-view.png` 在同一张画布内生成正面、正面三分之四、纯侧面和背面，是跨角度比例真值。人工检查时对齐：

- 头顶与下巴；
- 肩线与腰线；
- 开衫下摆与裙摆；
- 膝盖与脚底。

单角度生成只加载最接近目标视角的资产：

- 正面：`00-q-form-master-front.png`；
- 正面三分之四：`q-form-views/02-front-three-quarter.png`；
- 左向侧面：`q-form-views/03-left-profile.png`；
- 背面：`q-form-views/04-back.png`。

## 形态转换不变量

从标准形态转为正文轻 Q 形态时：

- 不改变脸型、红橙眼睛、成年感和克制表情；
- 不改变刘海分区、下巴长度短发与两侧稍长发束；
- 不改变白帽、居中红星与帽檐结构；
- 开衫缩到高胯附近，裙摆缩到大腿中上段；
- 肩宽适度保留，头宽不能等于整个身体宽；
- 手掌、膝盖、小腿与鞋保持明确结构，不做短粗幼儿肢体；
- 人物在画布中的总高度由构图决定，不能通过把整个人缩小来伪造 Q 感。

动态正文允许比例自然延展到约 4.0–4.7 头身，但仍应明显比标准形态紧凑。不要用精确数字压迫动作，也不要回退到旧 V2.1 三头身资产。

## 参考选择

每次只加载最少、直接相关的参考：

- 正文常规全身：V2.2 正面母版或最接近角度的单图，通常只需一张。
- 正文特殊动作：V2.2 对应角度图；只有动作容易漂移时再加动作表。
- 头肩近景：V2.1 身份母版 + 最接近角度的头部图。
- 标准形态侧面或背影：V2.1 身份母版 + 对应标准单视图。
- 人工审查跨角度一致性：查看 V2.2 统一四视图，不把整张拼板作为普通生成输入。

正文全身生成不得同时加载 V2.1 标准五视图、旧 V2.1 正文三头身图和 V2.2 轻 Q 图。文字声明权重不能可靠消除比例冲突。

## 一致性检查

1. 帽、星、刘海、侧发束和后发轮廓是否符合对应角度。
2. 开衫是否为敞开穿着；正面纽扣与背面结构是否正确。
3. 开衫下摆、裙腰、裙摆、膝盖、袜筒和鞋底是否保持同一套高度关系。
4. Q 感是否来自内部比例，而非总身高突然变矮、身体被截短或脸部幼化。
5. 是否保持成年、休闲、自然和独立，而非儿童、偶像、制服、服务或战斗角色。

身份、角度或比例错误时重生成对应资产，不用局部装饰掩盖结构问题。
