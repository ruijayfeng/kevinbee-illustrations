# 凯冰 V2.1：角色模型与参考路由

本文件定义如何使用角色设定资产。角色身份仍以 `ip-core.md` 为唯一文字真值；本文件不另写一套人格或服装设定。

## 权威顺序

发生视觉冲突时，按以下顺序判断：

1. `assets/ip-reference/v2.1/00-canonical-master.png`：脸、体型、服装、配色与整体气质。
2. `assets/ip-reference/v2.1/03-article-form-master.png` 与 `article-views/`：正文紧凑比例及其角度结构。
3. `assets/ip-reference/v2.1/head-views/` 与 `turnaround-views/`：指定角度下的头部和全身结构。
4. 表情表与动作表：情绪和姿态范围，不得反向改写身份。
5. V2 旧标准图和旧正文形态：仅用于迁移追溯，不再决定新图身份。

## 设定资产

### 身份母版

`00-canonical-master.png` 是唯一最高优先级视觉参考：成年、约 5.25 头身、轻微正面三分之四、中性站姿。所有新角度和新形态都从它派生，不混用旧图重新发明角色。

### 五视图

`01-turnaround-five-view.png` 用于人工总览。需要生成特定角度时，加载 `turnaround-views/` 中最接近目标视角的单张原图，不把整张拼板作为默认参考。

- `01-front.png`：面部对称、红星位置、正面服装结构。
- 母版：正面三分之四的主要身份视角。
- `03-left-profile.png`：帽檐、鼻面轮廓、后脑、侧缝与鞋型。
- `04-rear-three-quarter.png`：帽后扣、后发轮廓、开衫背部垂坠。
- `05-back.png`：帽子、头发、针织衫、裙褶和鞋跟的正背面结构。

五视图用于结构约束，不要求文章构图采用站姿或正交视角。

### 头部四视图

`02-head-construction-four-view.png` 用于人工总览。生成近景时按需加载 `head-views/` 中的一张：

- `01-front.png`：近景五官、眼距、脸型、红星位置与正面刘海的主要细节参考。
- `02-front-three-quarter.png`：帽檐、刘海与侧发束在主要身份视角中的重叠关系。
- `03-left-profile.png`：鼻口轮廓、耳位、帽檐投影和后脑层次。
- `04-back.png`：帽后扣、六片帽结构和后发收束。

身份母版仍高于近景图。近景图负责补充可见结构，不得用局部光影或细微五官差异改写母版身份。

### 正文形态与比例板

`03-article-form-master.png` 是 V2.1 正文静态形态参考，约 3.1–3.4 头身。`05-article-form-four-view.png` 用于人工总览；生成特殊角度时加载 `article-views/` 中的正面、侧面或背面单图。

动态正文允许自然延展到约 3.5–4.2 头身，以保证走、蹲、伸手等动作不产生幼态或肢体变形；仍须保持头部稍大、四肢较短，不能接近标准形态的修长轮廓。

`04-standard-to-article-scale.png` 把标准与正文形态按近似同高排列，仅用于人工理解比例转换，不作为普通生成参考图。

## 形态转换

标准形态约 5–5.5 头身；正文静态约 3.1–3.4 头身，动态可在保持紧凑轮廓的前提下延展至约 3.5–4.2 头身。正文形态只压缩躯干和四肢、适度放大头部，不改变：

- 脸部基本轮廓、红橙眼睛与成年感；
- 刘海分区、下巴长度短发、两侧稍长发束；
- 白帽、单颗居中红星与帽檐结构；
- 暗红开衫、象牙白上衣、藏青裙、深灰袜、浅色鞋；
- 安静、独立、不职业化的气质。

## 参考选择

不要默认加载全部资产。每次选择最少且直接相关的参考：

- 正文常规全身：以 V2.1 正文形态为主要视觉参考。身份母版用于人工核对，不默认与正文比例图同时加载，以免把身体拉回标准比例。
- 正面近景：身份母版 + 正面视图；情绪承载含义时再加表情表。
- 正文纯正面、侧面或背影：只使用最接近目标视角的正文单角度图作为主要参考；必要时再加正文形态母版。不要加载标准五视图。
- 头肩近景：身份母版 + 最接近目标视角的单张头部图；只有情绪承载含义时再加表情表。
- 标准形态纯侧面或背影：身份母版 + 对应单角度图。
- 特殊动作：身份母版 + 正文形态或动作表，最多三张。
- 角色设定或新比例派生：只从身份母版开始，再逐角度验证。

参考图超过三张时，先减少到真正约束当前问题的资产，避免不同尺度和姿态互相污染。标准形态与正文形态属于不同尺度层，不能在同一次正文全身生成中依靠文字声明权重来混用。

## 一致性检查

生成后先检查身份，再检查画风：

1. 帽、星、刘海、侧发束和后发轮廓是否符合对应角度。
2. 开衫是否为敞开穿着；正面有四枚深色纽扣，背面没有纽扣。
3. 裙腰、裙长、袜筒和鞋底是否保持同一结构。
4. 标准形态是否约 5–5.5 头身；正文静态是否约 3.1–3.4、动态是否保持在约 3.5–4.2 头身的紧凑范围。
5. 是否保持成年、休闲和自然，而非儿童、偶像、制服、服务或战斗角色。

身份或角度结构错误时重生成对应资产，不用局部装饰掩盖结构问题。
