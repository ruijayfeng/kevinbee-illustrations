# Q 版角色 IP 研究：凯冰正文形态的下一轮方向

> 2026-09-28。此文是设计研究与初步判断，不是角色定稿、生成提示词或新比例规范。只查阅权利方／制作方公开页面；“观察”和“推论”均不等同于对方公布的设计规则。

## 研究范围与判断方法

“Q”至少涉及内部比例重组、轮廓压缩、五官与衣装的信息取舍，以及小尺寸时还能读懂的动作。商品的实际厘米数只描述商品尺寸，不是插画的头身比。下表区分官方可证实的信息与从官方展示图、角色应用形式得到的设计观察。

| 路线 | 官方可证实的信息 | 设计观察／推论 | 对凯冰的适用度 |
|---|---|---|---|
| 人物 SD：Good Smile「黏土人」 | 官方日文介绍明确使用约 **2.5 头身**的变形角色；表情和手脚部件可更换以形成姿势。[来源：Good Smile 黏土人介绍](https://www.goodsmile.info/ja/aboutnendoroids)；初音未来 3.0 的官方制作说明写明，团队重新研究原画，再将形象适配为黏土人风格。[来源：Good Smile 初音未来 3.0](https://info.goodsmile.com/sp/nendoroid_hatsunemiku_3/en/) | **观察：**变形集中在头与躯干、四肢的关系，并保留原角色的发型、服装等识别线索。**推论：**人物 Q 版需要重新设计头身和四肢的结构、动作读法，而不只是等比缩小。2.5 是该系列的产品设定，不是凯冰必须遵守的数值。 | 最接近“同一位人物从标准形态转成 Q 形态”的问题；也提醒要保留动作可演性。 |
| 图形吉祥物：Sanrio「Hello Kitty」、LINE FRIENDS「BT21」 | Sanrio 官方指出 Kitty 左耳蝴蝶结是固定识别符号。[来源：Sanrio 品牌页](https://corporate.sanrio.co.jp/en/business-info/brands/hello_kity/)；LINE FRIENDS 说明角色起于聊天贴图，伴随日常情绪使用。[来源：LINE FRIENDS IP 页](https://linefriends.com/en/ip)。BT21 官方为 CHIMMY 指定黄色连帽衣，并分别给角色明确的性格与行为特征。[来源：BT21 角色页](https://linefriends.com/en/characters-list/ip-bt21) | **观察：**形状、局部标志与大色块先于衣纹、材质被看见；角色可以在多种心情与动作中维持识别。**推论：**对文章缩略图，凯冰应优先保住“白帽红星＋冰蓝头发＋红色上身块”的整体读法，随后才是开衫纽扣、褶皱、鞋带。 | 适合借用小尺寸识别方法；直接转成无骨架的符号吉祥物，会损失凯冰作为少女角色的动作和气质。 |
| 独立叙事角色：「Chiikawa」 | 官方动画介绍其故事同时有快乐、难过和朋友关系；官方角色页把 Chiikawa 的谨慎、紧张，与 Hachiware 的积极、Usagi 的活跃明确区分。[来源：动画官网](https://www.anime-chiikawa.jp/)、[来源：Chiikawa 官方角色页](https://www.chiikawaofficial.com/characters) | **观察：**极少的面部信息也能承载不同情绪，故事情境给简单形象增加人格厚度。**推论：**“很 Q”不必持续卖萌或使用夸张颜艺；凯冰的安静、犹豫、倔强可以靠眉眼、头部朝向、手部距离与停顿姿态来演。 | 适合借用“简单形状＋稳定性格＋情境反应”的逻辑；不照搬圆团身体或特定表情。 |

## 对现有凯冰母版的初步诊断

当前 [V2.2 正面母版](../kevinbee-illustrations/assets/ip-reference/v2.2/00-q-form-master-front.png)已修正过宽肩，但从正面图目测，头顶到下巴约占全身高度的五分之一左右；颈、腰、膝、小腿都按偏完整的人体来表达。袖褶、裙褶、鞋带、发丝和眼部层次也接近标准人物立绘。**这是视觉估计，尚未做像素测量或用户偏好测试。**它解释了“缩小版”的观感：角色在画布里变小了，造型语法仍接近标准版。项目早期 [角色方向稿](character-direction-v2.md)为正文形态提出约 2.8–3.2 头身，后来的 [V2.2 角色文档](../kevinbee-illustrations/references/character-model-v2.2.md)改为约 4.0–4.5 头身，并要求保留成年骨架、膝盖与小腿结构；这组约束本身也可能把 Q 化幅度限制得过轻。早期 [B2 正文候选](../archive/development-v2/explorations/05-b2-article-chibi.png)有更鲜明的 Q 感，但同样保留较多眼部、发丝和衣服细节，不宜直接恢复为正式母版。

## 下一轮可验证的方向

1. **人物型 Q 版作为主探索。**固定帽星、蓝发轮廓、眼色与红色衣块；尝试较明显的头部占比、短而完整的躯干与腿，并重画肩、手、鞋的相对体量。避免把黏土人的 2.5 头身直接当作凯冰目标。
2. **先测轮廓，后测细节。**同一站姿做黑色剪影和小尺寸预览，看帽檐、短发、红开衫外轮廓是否仍能辨认；再逐步去掉扣子、鞋带、密集发丝和褶皱，检查最少需要哪些细节。
3. **动作表演要保留。**用站立、回头、轻拉／接住三个动作测试：压缩比例后，手的方向、重心与人物同隐喻物的因果关系是否清楚。表情保持克制，只检查轻微疑惑、专注与安静满足是否可读。
4. **定稿由对照图决定。**下一轮宜用同一场景、同一画幅比较现有母版与若干不同 Q 化强度；分别看“像凯冰”“够 Q”“缩略图可读”“能参与隐喻”，不以单一头身比判定成功。

以上是对成熟路线的抽象，不以模仿任何具体 IP 的头形、眼形、嘴形或角色服装为目标。
