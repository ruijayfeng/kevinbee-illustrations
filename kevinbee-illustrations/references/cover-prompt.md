# 封面提示词组装

按下列顺序组织图像生成提示词；只放文章实际需要的内容。

1. **用途与画幅**：文章封面、目标平台或用户给定尺寸、需要保留的裁切安全区。
2. **主题与核心承诺**：区分文章完整标题与封面短主题词，用一句话说明读者点开后会看到什么，不把整句承诺写进画面。
3. **主对象、空间与凯冰**：一个具体对象、一处变化；同步描述道具与凯冰的相对位置、接触或因果关系，以及她的表情、动作、景别和画面占比。帽子红星、冰蓝短发、暗红开衫必须可辨；全身使用正式 V2.3 Q 版，近景按 V2.1 身份特征校准。
4. **构图与文字位置**：根据动作方向和主体体量决定文字区、前后层次及焦点；不预设固定位置。裁切时保住脸、红星、关键手势、主对象和全部文字。
5. **视觉质感**：凯冰身份稳定，色彩和道具材质按主题变化；标题可按需要使用立体光影或柔和下缘渐隐，但不固定套用。
6. **文字策略**：无字版明确不出现文字；有字版写出已确认的准确短标题，禁止额外单词、Logo 或水印；逐字核验失败则转无字版排字。
7. **排除项**：多案例拼贴、信息图网格、无关 UI、小字、Logo 乱造、角色立绘式站姿、复杂背景抢主体。

生成后保留原图，再按目标平台制作裁切候选。裁切不是重构：不能切掉红星、眼睛、主动作或标题安全区。
