# 凯冰文章视觉：正文配图与封面

正文与封面是并列能力：正文模式把认知锚点转成手绘解释图；封面模式把文章主题转成信息流中一眼能读懂的主视觉。凯冰是白帽红星、冰蓝短发、暗红开衫的日系休闲少女；她进入画面的核心关系，但不是战士、固定工作人员或装饰吉祥物。

固定的是凯冰的身份，不是她每次出现的动作和构图。先为当前文章发明隐喻，再让视觉参考校准角色；不要从资产库挑一张姿势后反向套题。

## 当前能力

当前正式支持：

- `article-body`：文章分析、shot list、单张或成组正文配图，以及已有正文图的局部修改；
- `cover`：从文章主题与核心承诺规划或生成封面主视觉，并检查缩略图识别、文字与平台裁切。

封面与正文图使用不同的画幅、信息层级与验收规则。角色设定稿不在本 Skill 范围内。

## 关系与按需读取

每个文件只负责一个决策层，后层不得重写前层：

| 决策层 | 单一真值 | 何时读取 |
|---|---|---|
| 角色是谁 | `references/ip-core.md` | 每次涉及凯冰形象 |
| 比例、角度与参考选择 | `references/character-model.md` | 生成、修改或核对角色 |
| 隐喻与构图 | `references/composition-patterns.md` | 规划 shot list 或发明隐喻 |
| 文章图片角色 | `references/article-image-roles.md` | 文章已有截图、结果图或对照图时 |
| 正文视觉语言 | `references/article-body-style.md` | 生成正文图 |
| 封面内容构思 | `references/cover-concept-method.md` | 从文章提出封面方向或生成封面前 |
| 封面研究图拆解 | `references/cover-examples.md` | 每次构思封面时，提炼布局、发散方式、人物参与和标题安排 |
| 封面视觉语言 | `references/cover-style.md` | 用户要封面主视觉时 |
| 提示词组装 | `references/article-body-prompt.md` | 调用图像工具前 |
| 封面提示词组装 | `references/cover-prompt.md` | 调用图像工具生成封面前 |
| 验收与返工决策 | `references/qa-checklist.md` | 检查或修改图片 |
| 封面验收 | `references/cover-qa.md` | 检查封面与缩略图时 |
| 可加载资产 | `assets/manifest.yaml` | 隐喻和动作已确定后选择最少参考 |

封面默认使用标准形态，正文使用 Q 版形态。两者是同一凯冰，但正文 Q 版不自动带入封面。Q 版封面尚未通过视觉验收。角度单图按当前画面选用，没有固定优先级；资产不能反向决定隐喻、动作或构图。

## 工作流

### 理解正文

提炼文章的核心判断、认知转折、关系变化和真正值得视觉化的段落。不要平均配图，也不要把每个小标题都变成图。

先盘点文章已经包含或明确将提供的图片，并按 `references/article-image-roles.md` 标注输入、过程、结果、失败、对照或概念解释。产品体验、教程和项目复盘优先保留能证明过程与结果的真实画面。概念插图不能代替实测证据。

优先选择：核心判断、前后状态、选择与分流、关系断点、输入输出、风险、承接路径或情绪变化。不适合视觉化的段落保留为文字。

### 规划

用户只要求分析或配图建议时，输出 shot list，不生成图片。每张包含：

- 放置位置
- 主题与核心意思
- 结构类型
- 凯冰如何进入核心关系，以及移除她后会失去什么
- 主要物件或空间关系
- 可选短标注

张数由真实认知断点决定，可以为 0。已有过程与结果画面已经承担叙事时，明确输出“本篇无需新增正文隐喻图”，不要为了完整感凑图。

### 生成正文图

用户明确要求生成、做图或输出时，直接逐张使用图像生成工具，不把多张图拼成一张。

每张图：

- 只表达一个核心意思。
- 默认 16:9 横版、白色或极浅暖白背景。
- 先确定隐喻、空间关系和凯冰的参与方式，再选择最少的身份参考。常规场景只需正文 Q 版正面母版或最接近目标角度的单图；只有身份、动作或表情确实容易漂移时，才补充一张直接相关的参考。
- 在符合文章含义的候选中变化隐喻载体、角色位置、观察角度或动作，不重复套用同一资产姿势；随机性不得改变凯冰身份。
- 让凯冰经历、选择、承受、同行或影响核心关系；观察只有在她的位置、姿态或反应本身构成因果关系时才成立。只有文章隐喻确实需要时才操作物件。
- 做一次删除测试：移除凯冰后，若核心动作、因果张力和选择关系都没有明显减弱，重新设计她的参与方式。
- 默认不写字；若脱离正文无法在一秒内判断主要关系，使用 1–3 个短中文标注辅助解码。
- 为当前文章重新发明隐喻，不复刻案例。

图像工具若返回 3:2，保留原图，再制作 16:9 版本；裁切前检查帽子、红星、手脚、核心物件和留白不会受损。

### 封面模式

用户明确要求封面时，按以下顺序执行；不套用正文图的画幅、留白比例或隐喻图验收：

1. 读取 `references/cover-concept-method.md`、`references/cover-examples.md` 与 `references/cover-style.md`。研究四张内容构思图及既有封面的整体布局、思路发散、凯冰参与和标题分工，必要时打开原图核对；它们提供设计判断，不是可选模板。从当前文章确定主对象、一个核心张力与目标画幅，构思至少两种不同的可见事件，再选最准确的一种。
2. 区分文章长标题和封面短主题词：用户给了封面文案时按原文使用；若只给文章标题，可提炼短词，生成前确认，除非用户已明确授权直接选择；无字版保留可排字区域。先确定目标画幅再组织构图；未给尺寸时交付横版母图，注明平台裁切尚未验证。
3. 把选中的事件写成当前文章专属的封面方案：主对象和变化、凯冰的动作与情绪、视线流向、前后层次、标题区域及裁切安全区。按 `assets/manifest.yaml` 加载已修正肩袖比例的标准形态母版校准凯冰，必要时补一张相关角度身份参考。封面案例与研究图不作为生图输入；近景动作仍需防止透视放大肩臂。
4. 调用图像工具前读取 `references/cover-prompt.md`，用文字描述这篇文章的新方案。人物、主题道具、空间关系、神情、动作、景别、占比和文字区域共同服务同一事件；保持一个可辨主对象与变化，人物是能辨认神情与动作的主要视觉层之一。

封面保存至：

```text
assets/<article-slug>-cover/
```

按 `references/cover-qa.md` 检查实际返回尺寸、目标裁切成品和约 240px 宽缩略图。封面失败时先简化构图和主体数量，不用增加装饰挽救。有字封面若文字核验失败，不能把无字母图当作已完成的有字封面交付。

### 正文图验收与交付

按 `references/qa-checklist.md` 检查。身份或核心隐喻错误时重生成；局部文字、留白或多余元素问题可编辑修正。

项目内输出保存至：

```text
assets/<article-slug>-illustrations/
```

按顺序命名，不覆盖已有资产。交付时说明图片用途、最终路径，以及任何仍需用户判断的候选版本。

## 不变量

- 角色身份以 `references/ip-core.md` 为准，其他文件不得另建角色设定。
- 凯冰不是固定职业，也不承担“为内容服务”的人格设定。
- 默认形象不出现武器、战斗服、长斗篷、战术装备或英雄式姿态。
- 角色参与不等于必须操作机器；但单纯站在旁边观看、只增加气氛，不算进入核心关系。
- 正文配图不是 PPT、流程图皮肤、角色海报或课程页。
