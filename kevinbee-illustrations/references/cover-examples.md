# 封面研究图：提炼设计方法

这些成图帮助理解**整体布局、思路发散、凯冰的参与方式和标题安排**。每次做封面先读文章，再读本文件，把方法转成当前文章独有的画面。图像生成只加载 `assets/manifest.yaml` 中的人物身份参考；下列封面供观察和分析，**不作为生图的图像输入或套用模板**。

四张内容研究图由用户提供的其他作者封面启发，但没有对应文章原文；下文对内容关系的解释是设计假设，不是产品能力或文章事实。所有示例都不能校准肩峰、袖量或骨架，四张研究图的人物肩袖比例尤其尚未合格。

## 从四张研究图读到的决策

### [多结果分岔](../assets/cover/concept-studies/qwen-branching.png)

- **布局**：一个发光起点连接向外展开的结果，分支占据画面上部和左侧；人物与起点占右侧，大片底部文字把繁多细节收束为一个主题。
- **凯冰**：双手托住起点，眼神追随展开方向。她让“从一到多”有一个可见的起因和观察视角。
- **标题**：用短的模型或主题名确认读者看的是什么；不把所有结果写成文字清单。
- **可迁移判断**：当文章确实强调同一来源带来的多样结果时，让一个明确起点统领变化；结果数量、媒介、人物位置和标题区域由当前文章重定。

### [进入产品世界](../assets/cover/concept-studies/hyper3d-forward.png)

- **布局**：道路、车辆和环境形成向画面深处的动线；人物是进入场景的视觉锚，标题成为场景中的大型路牌。
- **凯冰**：身体前倾、握住车把，表情回应体验。她在运动中，而不是站在旁边介绍世界。
- **标题**：产品名被放入可读的场景物件，字是阅读入口，也属于空间的一部分。
- **可迁移判断**：当文章重点是“进入一种体验”，先找能引导视线的空间或动作；交通工具、伙伴和路牌都不是默认元素。

### [动作冲击](../assets/cover/concept-studies/fighting-skill-impact.png)

- **布局**：近景动作形成最强焦点，人物脸和身体接住它，背景动线加强方向；标题放在动作留下的清晰区域。
- **凯冰**：身体重心、另一只手和目光支持同一动作，不是只有一只悬空的大拳头。
- **标题**：短词点明技能，画面负责传递冲击；文字避开脸和动作接触点。
- **可迁移判断**：强透视只在文章真的需要动作冲击时成立；战斗姿态和前景拳头不能成为凯冰的常态形象。

### [一次示范带出后续](../assets/cover/concept-studies/teach-once-causal.png)

- **布局**：前景触发点、人物和右侧结果形成可追踪的因果路径；标题占据上方相对安静的区域。
- **凯冰**：手按下第一次触发，目光跟随结果。她完成关键一步，而后续变化沿路径发生。
- **标题**：一个短问题提出读者想知道的事，画面中的动作和结果共同回应它。
- **可迁移判断**：教程、自动化或代理类文章可寻找“谁触发了什么变化”；鼠标、助手和步骤卡片须由当前文章决定。

## 转成新文章封面

1. **从内容发散**：写出文章的主对象、读完会理解的变化和证据。提出至少两种不同的可见事件，变化应来自不同动作、空间关系或观察角度，不能只是换颜色或左右位置；四张研究图不是候选菜单。
2. **选一个瞬间**：挑最准确、最能在缩略图读懂的事件。先画出主对象、变化方向和凯冰的接触点，再决定人物景别、机位、前后层次与背景。元素围绕一个焦点组织，保留标题和裁切所需的安静区域。
3. **让凯冰进入因果**：她可以发现、触发、承接、跨入或被变化影响。目光、手势、重心和表情指向同一事件；移除她后，动作关系或阅读张力应明显变弱。
4. **给标题分工**：封面短词只命名对象、能力或提出核心问题；画面演出发生了什么。按场景的安静区域、运动方向和目标裁切决定字的位置、体量和字效。标题可与空间融合，也可独立成块；保持逐字准确和缩略图可读。
5. **写新方案再生图**：提示词描述当前文章独有的对象、事件、凯冰动作、标题与版面。研究图只帮助思考上述决策，生图不加载研究图；人物身份使用标准形态母版。成图按 `cover-qa.md` 检查内容、剪影、文字和最终裁切。
