# 凯冰文章封面视觉语言

封面负责让读者在信息流缩略图中认出主题与张力。它不是正文隐喻图放大版，也不是角色海报。

## 信息层级

1. 一个文章主对象：模型、界面、图片、文件、装置或能代表任务的具体物件。
2. 一个可见张力：错位、连接、拆开、推进、失控、修复、对照或出乎意料的变化。
3. 凯冰进入张力：她可以发现、追赶、试探、推动、避让、接住或被结果影响。她不是站在旁边介绍产品。
4. 标题安全区：无字图也要留出干净区域，避免主体铺满后无处排标题。

## 与正文图的区别

- 封面在小尺寸仍要认出主对象和动作，可使用更近景的角色、更强轮廓和更集中的色彩。
- 不要求正文图的 35% 安静留白；留白服务标题和裁切，而非解释关系。
- 背景可以有简化场景与明暗层次，不限纯白，但不能变成复杂写实海报或商业 3D 渲染。
- 一张封面不同时塞入文章的全部案例。选择最能兑现标题的一件事。

## 文字

默认生成无字主视觉，让排版阶段添加准确标题。用户明确要求图内文字时，只放一条短标题；产品名、版本号和中文必须逐字核对。图像生成器无法稳定写对时，回退无字版，不以错字交付。

## 变化

同一文章可给 2–3 个方向草案：对象主导、角色反应主导、前后冲突主导。方向差异来自构图与叙事角度，不是只换背景色。
