# 凯冰 V2 角色方向稿

> 状态：工作基线，供角色探索、参考图制作与 Skill 重构使用。  
> 目标：将凯冰从偏战斗的动漫角色，调整为适合文章配图、封面和长期个人 IP 使用的日系休闲少女。

## 1. 核心定义

凯冰是一位清新、安静、有主见的日系休闲少女。

她进入由观点、情绪、关系和抽象概念构成的画面，自然地观察、经历和参与其中。她不是被派去完成工作的助手，也没有固定职业；配图服务于内容，但凯冰始终是独立、完整的角色主体。

一句话视觉方向：

> 白帽红星、冰蓝短发的日系休闲少女，在清爽、略带想象力的概念世界里自然生活与行动。

## 2. 角色气质

### 必须保留

- 清新、安静、克制。
- 有主见，带一点轻微的倔强和疏离感。
- 好奇但不夸张，情绪真实但不表情包化。
- 可爱来自比例、动作和反差，不来自撒娇、幼态或甜腻装饰。
- 面对奇怪场景时保持自然，像那个世界本来就属于她。

### 不要出现

- 战士、刺客、冒险者或任务执行者气质。
- 内容助理、现场操作员、维修员等职业化身份。
- 偶像、甜妹、儿童吉祥物或过度卖萌形象。
- 过度悲情、冷酷、攻击性或英雄式姿态。

## 3. 识别系统

识别点按优先级排列。角色在任何画幅、比例或场景中，至少保留前三项。

1. 略有生活感的白色棒球帽，正面一枚清晰的红色五角星。
2. 冰蓝色、齐下巴附近的轻盈短发。
3. 红色或红橙色的服装色块。
4. 红橙色眼睛与安静、专注的表情。
5. 米白、炭灰、藏青组成的休闲穿搭底色。

红星白帽是第一识别点，但不应被画成军帽、制服帽或带有强烈军事意味的帽型。

## 4. 默认外形

### 头发与面部

- 冰蓝色短发，长度在耳下至下巴之间。
- 发梢轻微外翘，轮廓蓬松但不过度凌乱。
- 刘海自然，不遮住帽子红星和主要表情。
- 眼睛为克制的红橙色，不使用复杂高光和浓重睫毛。
- 面部清爽，减少精细动漫立绘式妆感。

### 默认服装

- 白色红星棒球帽。
- 米白或浅灰的宽松内搭。
- 柔和暗红色针织开衫，长度在腰部至胯部之间，轮廓松弛。
- 炭灰或藏青色短裙；需要更强动作时可替换为同色宽松短裤。
- 黑色或深灰短袜。
- 简洁帆布鞋或轻便圆头短靴。

红色针织开衫是旧斗篷的温和替代：保留角色身上的标志性色块，但将叙事从战斗感转向日常、柔和与长期陪伴感。开衫使用完整下摆、简单罗纹和少量自然褶皱，不加入制服或功能服装细节。

### 可选配饰

- 简洁小挎包。
- 耳机、书、相机、雨伞等与当前场景有关的日常物件。
- 少量发夹或手环，但不能形成新的核心识别点。

配饰必须由当前叙事决定，不固定为职业工具包。

## 5. 正式比例

### 正文配图形态

- 约 2.8–3.2 头身。
- 轮廓简洁，手脚偏小但动作清楚。
- 表情减少细节，保证缩小后仍然可读。
- 角色通常占画面面积的 15%–30%；当角色本身承载情绪时可提高。

### 封面与 IP 展示形态

- 约 5–5.5 头身。
- 可以增加发丝、服装结构和表情细节。
- 仍保持休闲、轻盈，不回到写实人体或精细战斗立绘。

两种形态共享同一帽型、发型、面部特征、服装配色和性格。比例变化不能被理解为两个不同角色。

## 6. 动作语言

凯冰通过自然动作参与画面，不承担固定工作职责。

### 推荐动作

- 站、走、坐、蹲、靠、回头、探身、踮脚。
- 观察、等待、犹豫、思考、跟随、躲避、保持平衡。
- 抱住、牵住、推开、轻拉、扶起、接住、放下。
- 从盒子或门后探头，坐在巨大物件旁，沿路径前进。
- 被信息、情绪或结构影响，并自然作出反应。

### 谨慎使用

- 修理、分拣、操作机器等动作可以出现，但只能由当前隐喻自然产生，不能成为固定职业设定。
- 夸张奔跑、跌倒或惊讶可以偶尔使用，不能把角色变成喜剧吉祥物。

### 默认禁止

- 持刀、拔剑、战斗、警戒、攻击。
- 武器、剑鞘、战术装备、重型工具。
- 英雄落地、迎战、冲锋等战斗构图。

## 7. 表情范围

建议建立以下常用表情：

- 平静默认。
- 专注观察。
- 轻微疑惑。
- 若有所思。
- 小幅度开心。
- 轻微无奈。
- 有一点倔强。
- 完成某件事后的安静满足。

避免大哭、大喊、星星眼、夸张害羞、颜艺和战斗怒容。

## 8. 画面语言

- 以清爽的日系编辑插画为主要方向。
- 线条轻、自然、有少量手绘感，但不脏乱。
- 白色或极浅暖白背景。
- 使用冰蓝、柔和红橙、米白、炭灰和少量肤色。
- 阴影和水彩质感克制，避免厚涂、强光影和商业动漫海报感。
- 服装与五官细节应能随画面缩小而简化。
- 正文配图中，概念关系与凯冰共同构成画面，而不是用信息图框架包围角色。

## 9. 场景中的角色位置

### 主角型

凯冰的状态本身表达文章观点。适合情绪、选择、成长、迷茫和转变主题。

### 同行型

凯冰与一个物件、路径或空间关系共同表达观点。这是正文配图的默认方式。

### 点睛型

凯冰只占较小面积，通过姿态和红星白帽建立识别。适合结构较强、角色不宜抢占信息层级的画面。

不再强制每张图都让凯冰操作装置。观察、经历、靠近、跟随和被影响同样是有效参与。

## 10. 旧版元素处理

| 旧版元素 | V2 处理 |
|---|---|
| 白帽红星 | 保留并优化为休闲棒球帽 |
| 冰蓝短发 | 保留，适度简化 |
| 红橙色眼睛 | 保留，降低精细度 |
| 猩红长斗篷 | 替换为柔和暗红色针织开衫 |
| 黑色战斗裙 | 替换为简洁深色短裙或短裤 |
| 战术腰带与颈圈 | 移除 |

| 厚重战靴 | 替换为帆布鞋或轻便短靴 |
| 战斗姿态 | 移出默认动作库 |

旧战斗版本可以保留为历史版本或特殊世界观皮肤，但不得继续进入默认生成上下文。

## 11. 第一轮视觉探索

第一轮只探索服装轮廓，不同时改变脸、发型、比例和画风。

### 方案 A：短款连帽外套

- 红色短款连帽外套。
- 米白宽松内搭。
- 炭灰短裙。
- 深色短袜与帆布鞋。

特点：品牌红色最稳定，能够自然继承旧版斗篷的动态感。作为首选方向。

### 方案 B：宽松红色开衫

- 柔和红色针织开衫。
- 白色圆领上衣。
- 藏青短裙。
- 简洁圆头鞋。

特点：更生活化、更温和，但需要避免过于普通或校园化。

### 方案 C：浅色外套与红色披肩

- 米白休闲外套。
- 炭灰内搭与短裤。
- 小面积红色披肩或肩部色块。

特点：整体最清新，红色识别面积较小，需要测试缩略图识别度。

三套方案使用同一站姿、同一面部、同一背景和同一画幅进行比较。

## 12. 定稿标准

候选形象必须同时满足：

- 不依赖刀剑仍能一眼识别为凯冰。
- 第一印象是日系休闲少女，不是战斗角色或工作人员。
- 清新可爱，但不过度幼态和甜腻。
- 缩小进入文章配图后仍能看见红星白帽、冰蓝短发和红色色块。
- 能自然适配安静、抽象、幽默和稍有情绪的不同文章主题。
- 连续生成时服装轮廓与帽型具有足够稳定性。

未通过角色定稿前，不批量替换现有文章示例，不把探索图写入正式 Skill 上下文。

## 13. 第一轮探索结果

候选图保存在 `archive/development-v2/explorations/`，目前仅用于方向比较，不进入 Skill 运行时。

### A：红色短款连帽外套

- 优点：红色识别最强，与白帽、蓝发形成清楚的品牌色关系；从旧斗篷迁移到休闲形象最自然。
- 风险：外套体积过大时会重新产生英雄外套或轻战斗感。
- 下一轮调整：缩短衣长、减小袖子体积、降低红色明度和褶皱复杂度。

### B：红色宽松开衫

- 优点：最温和、最生活化，容易进入安静文章场景。
- 风险：整体较普通，可能削弱凯冰独有的轮廓；也容易靠近校园少女气质。
- 下一轮调整：保留针织柔和感，但需要更独特的领口、下摆或红色色块设计。

### C：米白外套与红色肩部层次

- 优点：最清新、最轻盈，适合封面和日常视觉。
- 风险：红色肩部外搭仍有退回披肩或斗篷的可能；服装层次稍多。
- 下一轮调整：将红色部分明确为日常针织衫或短外搭，减少垂坠长度。

### 已选方向

选择 B 作为 V2 主方向，核心理由是它提供了更自然的柔和感和长期陪伴感，同时不会给角色附加战斗、职业或功能身份。

第二轮 B2 已收敛为：白帽红星、冰蓝短发、象牙白圆领内搭、胯部长度的柔和暗红针织开衫、藏青 A 字短裙、深灰短袜和浅色休闲鞋。

- `archive/development-v2/explorations/04-b2-standard-form.png`：封面与 IP 展示候选基准。
- `archive/development-v2/explorations/05-b2-article-chibi.png`：正文配图三头身候选基准。

B2 仍属于候选资产。在完成表情、动作和至少三种正文场景验证之前，不进入正式 Skill 的默认上下文。

## 14. B2 验证结果

早期验证资产保存在 `archive/development-v2/validation-v2.1/`。图像模型返回的正文原图为 3:2，原始文件保存在其 `raw/` 子目录；被选为正式示例的 16:9 版本只保存在 Skill 的 `assets/article-examples/`，不在归档区重复保存。这些文件只用于设计追溯。

### 表情与动作

- 表情稿中的帽型、红星、发型、眼睛和开衫领口保持稳定。
- 平静、思考、轻微疑惑、小幅开心、无奈和安静满足均能成立，没有明显表情包感。
- 自然动作稿验证了走、坐、蹲、回头、平衡、抱纸、探头和开门。
- 动作不依赖武器、职业工具或任务身份，角色主体感成立。

### 正文场景

- 信息过载：通过凯冰牵住一根清晰红线表达“从噪声中选择信号”，角色是经历者，不是工作人员；通过。
- 决策路径：通过停在纸路分岔口观察红色标记表达选择，休闲气质和留白稳定；通过。
- 信任桥：角色一致性和自然参与方式通过，但“卡片搭桥”与旧案例隐喻接近；仅作身份验证，不进入正式示例库。

### 阶段判断

B2 已通过角色识别、表情范围、自然动作和正文场景适配的首轮验证，可以作为后续 Skill 重构的 V2 角色基准。正式案例仍需从当前文章重新发明隐喻，避免把本轮验证构图固化成模板。
