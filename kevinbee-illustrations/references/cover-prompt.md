# 封面提示词组装

按下列顺序组织图像生成提示词；只放文章实际需要的内容。

1. **用途与画幅**：文章封面、目标平台或用户给定的最终尺寸；根据图像工具可能返回的母图比例，预留足够的裁切安全区，把文字、帽星、脸和主动作放在最终可见区域。
2. **主题与核心承诺**：区分文章完整标题与封面短主题词，用一句话说明读者点开后会看到什么，不把整句承诺写进画面。
3. **主对象、空间与凯冰**：一个具体对象、一处变化；同步描述道具与凯冰的相对位置、接触或因果关系，以及她的表情、动作、景别和画面占比。以 V2.1 标准母版为人物参考，保持自然肩颈、成年比例和有表现力但不夸张的神情与手势；白帽红星、冰蓝短发、暗红开衫必须可辨。人物是封面主视觉之一，不是边缘小点。
4. **构图与文字位置**：根据动作方向和主体体量决定文字区、前后层次及焦点；不预设固定位置。裁切时保住脸、红星、关键手势、主对象和全部文字。
5. **视觉质感**：凯冰身份稳定，色彩和道具材质按主题变化；标题可按需要使用立体光影或柔和下缘渐隐，但不固定套用。
6. **文字策略**：封面短主题词已确认时，作为与人物、道具共同构图的主要信息层；用户要无字版时明确不出现文字。有字版写出准确短标题，禁止额外单词、Logo 或水印。逐字核验失败时可局部修正或改用无字母图后续排字；若用户要的是有字成品，补字并重新核验前不得称为完成。
7. **排除项**：多案例拼贴、信息图网格、无关 UI、小字、Logo 乱造、角色立绘式站姿、复杂背景抢主体。

生成后先读取实际尺寸，保留原图，再按目标平台制作裁切候选。提示词中的横版要求不等于实际返回横版；只验原图、不验最终裁切不算完成。裁切不是重构：不能切掉红星、眼睛、主动作或任何标题字形；安全区失败时重新构图。
