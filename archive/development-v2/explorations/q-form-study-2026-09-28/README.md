## 本轮提示词的控制项

- 两张正面稿使用同一当前母版、正面自然站姿、纯白背景和完整全身。固定白帽红星、冰蓝短发、红橙眼、暗红敞开开衫、浅色内搭、藏青短裙、深袜浅鞋与克制气质。
- 中档要求重构为约 3.3–3.5 头身：相对放大头帽、缩短躯干与双腿、减小肩部和上臂体积，简化发束、衣褶、扣子和鞋带。
- 强档要求重构为约 2.7–2.9 头身：更短的颈、躯干与腿，保留能持物、迈步和平衡的小手与关节；突出帽星、发型和红色衣块，不转为圆团吉祥物或儿童表情。
- 两张场景图使用同一隐喻说明：凯冰携带一只将要展开的纸鹤，穿过暗红线围出的临时边界，另两只纸鹤留在外侧。画幅 16:9，人物约占 20%–25%，白底轻线稿、无文字。各自只使用对应候选图作为角色参考。

## 暂时判断

强档在静态和远景中都有更明确的 Q 版识别，值得作为下一轮重点；中档保留较完整的人体比例，可作为比较基线。两张场景图虽然用了相同文字提示，但模型改变了纸鹤位置和角色站位，不能仅凭场景质量给形象定稿。

### 本轮提示控制

- 四视图：同高、同一头帽尺寸、肩腰裙摆与膝脚高度关系一致；红星只在帽子正面，背面展示帽扣与后发。
- 低座：当时提示要求短而自然的斜向大腿、轻薄膝盖、小鞋、无前景夸张透视；现将圆厚的腿鞋视为可选 Q 版造型，而非失败条件。
- 地面侧坐：不使用座椅，双腿折向一侧，小手支撑身体，避免圆柱形大腿和巨鞋。
- 新场景：取文章“同时保留太多可能会提前分走注意力”的判断，用三个实体折纸门和细线的牵引表现；凯冰占画面约 20%–25%，白底横版，默认无文字。此隐喻由文章决定，不从旧纸鹤场景复制。
- 局部编辑：只删除汗滴和脸侧漫画提示线，其余人物身份、牵引关系、构图与色彩保持不变。

### 当前判断

强档已在正面、转身、伸手、地面侧坐和两种不同正文隐喻中保持可识别的角色身份与明显 Q 感。低座坐姿允许偏幼态的比例；仍需检验动作可读性，四视图也需要在单角度生成和更小显示尺寸下继续检验。现阶段足以把强档作为优先探索方向，不足以直接替换 Skill 的 V2.2 正式资产与比例规则。

### 本轮提示控制与边界

- 单角度：完整全身、白底、同一窄肩和紧凑躯干；红星固定在帽子正面，随头转向露出不同面积，不得在帽后复制。
- 表情：固定帽、发、眼、衣与头肩轮廓，只以眉眼和嘴角表达轻变化；禁止汗滴、泪、强调线和夸张兴奋神情。
- 正文场景：另取文章“熟悉很多开头，却很少抵达中段”的段落，用短的中止线和一条持续推进的线表达，不沿用前轮纸鹤或纸门；人物必须亲自画出长线，而非站在隐喻旁边。
- 数字头身是提示目标而非实测值。当前单人角度有回弹，正式转换前须统一下肢和袖量，并在真实文章版式的小显示尺寸下验收；统一的是角色识别和造型逻辑，不是排除幼态比例。人物形象应固定，隐喻物和行动随文章内容变化；本次铅笔不是默认优先资产。
- 侧视修正以 `15` 为编辑目标、`02` 为比例参考，只调整头部以下的腿长和袖量；保留原稿对照，未覆盖旧图。腿部厚度不再单独构成问题，多角度是否定型仍须看造型连续性。
