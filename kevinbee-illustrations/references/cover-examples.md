# 封面设计参考：选择与使用

封面是与正文配图并列的 Skill 功能。先读文章，确定主对象、阅读承诺、可见事件、凯冰的参与方式和目标画幅；完成构思后，再查看下列成图，比较人物、主对象、标题与空间的关系。每篇文章重新决定隐喻、动作、景别、站位、道具和字效。

人物身份与比例始终按 `character-model.md` 和 `assets/manifest.yaml` 中的标准形态参考校准。**下列封面均不用于校准肩峰、袖量或骨架**；现有标准母版的肩袖外轮廓仍待验收。

## 选择与加载

1. 先写出这篇文章的「主对象 → 变化 → 凯冰动作」和封面短词，再找设计参考。只按**内容关系**选，不按产品类别或标题关键词套图。
2. 若一张案例能帮助表达已经确定的事件，可把它作为**一张**额外的图像输入，并写明只借鉴哪一种关系：信息层级、视觉动势、空间深度或标题与事件的结合。四张内容构思研究图可以这样使用。
3. 同一次生成还要使用标准形态母版校准凯冰；在提示词中分别声明人物参考与设计参考的职责。新文章的主对象、角色动作、机位、站位、配色和标题由当前内容决定，不从案例继承。研究图中的宽肩、袖量和夸张手臂不继承。
4. 找不到贴合内容关系的案例时只用人物母版。若图像工具把设计图的姿势、布局或宽肩复制到新图，改用文字概括设计关系重新生成，并按 `cover-qa.md` 复查。

## 内容构思研究

这四张以用户提供的其他作者封面为设计参考、以凯冰标准母版为身份参考重新生成。原始对应文章未提供，表中内容关系是从画面反推的**设计假设**，不代表产品能力或文章事实。它们可在对应内容关系成立时作为封面设计参考输入；研究图中的肩袖比例尚未合格。

| 成图 | 假设的内容关系 | 可复盘的事件 |
|---|---|---|

| [进入产品世界](../assets/cover/concept-studies/hyper3d-forward.png) | 进入有鲜明质感的空间 | 人物骑行进入场景，标题成为路景的一部分。 |

这些图保存的是**封面功能的设计资料**。设计参考只帮助表达已从文章确定的关系，不证明产品能力，也不成为固定模板。短标题、图内文字、实际尺寸和最终裁切仍按 `cover-prompt.md` 与 `cover-qa.md` 验收。
