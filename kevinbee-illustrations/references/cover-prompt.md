# 封面提示词组装

按下列顺序组织图像生成提示词；只放文章实际需要的内容。

1. **用途与画幅**：文章封面、目标平台或用户给定尺寸、需要保留的裁切安全区。
2. **核心承诺**：用一句话说明读者点开后会看到的冲突或结果，不直接把整句写进画面。
3. **主对象与张力**：一个具体对象、一个动作或变化，明确前后和空间关系。
4. **凯冰参与**：帽子红星、冰蓝短发、暗红开衫；描述她如何被卷入核心动作。根据封面可使用半身、近景或全身，不强制正文轻 Q 的远景比例。
5. **构图**：焦点、标题安全区、裁切时必须保住的脸、红星和主对象。
6. **风格**：凯冰 V2 手绘身份，清楚轮廓、适量场景、控制色彩；缩略图仍可辨。
7. **文字策略**：默认无字；需要短标题时写出准确文本并要求不添加其他字。
8. **排除项**：多案例拼贴、信息图网格、无关 UI、小字、Logo 乱造、角色立绘式站姿、复杂背景抢主体。

生成后保留原图，再按目标平台制作裁切候选。裁切不是重构：不能切掉红星、眼睛、主动作或标题安全区。
